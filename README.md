# Rescate

Plataforma web para la publicación y rescate de excedentes de alimentos.
Proyecto IIC3143, 2026-2.

## Frontend

La aplicación web está en `frontend/` y utiliza React, TypeScript y Vite.

### Requisitos

- Node.js 22 o superior
- npm

### Instalación y desarrollo

```bash
cd frontend
npm install
npm run dev
```

Vite mostrará en la terminal la dirección local para abrir la aplicación;
normalmente es `http://localhost:5173`.

### Compilación

```bash
cd frontend
npm run build
```

Para revisar el estilo del código se puede ejecutar `npm run lint` desde
`frontend/`.
